# index-tts2/examples/

Example metadata for IndexTTS2 inference. The JSONL file references prompt audio names such as `voice_01.wav`; those audio files are not stored in the current source tree and must be provided separately if you want to run the examples.

## Files

| File | Purpose |
|---|---|
| `cases.jsonl` | One JSON object per line with fields such as `prompt_audio`, `text`, and `emo_mode` |
